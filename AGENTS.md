## Project Purpose

This repository contains OpenCV and ROS computer-vision class materials, including example scripts, sample images, and Gazebo-related lane-detection code.

## Rules

- Treat this as class/practice material unless the user asks to turn it into a polished portfolio project.
- Do not claim benchmark performance or autonomous-driving readiness.
- Keep sample images and PDFs only when they are relevant to the examples.
- Add reproducible run commands when editing README content.
- Do not remove large PDFs or sample images without explicit user approval.

## Documentation Expectations

- Explain each folder briefly.
- List Python/OpenCV/ROS dependencies.
- Mark missing demo outputs as `TBD`.
- Prefer concise setup and run examples over broad claims.
